ESP32-WROOM-32 · DevKit USB-C (CP2102)

Installer Wi-Fi Radar

Cette page installe le microprogramme sur votre carte, depuis un ordinateur Ubuntu, avec Chrome ou Edge. Elle a besoin d’un câble USB-C qui transporte les données (pas seulement la charge). L’installation n’a pas encore été essayée sur une vraie carte : le microprogramme a seulement été compilé.

Utilisez Google Chrome (paquet .deb) ou Edge sur l’ordinateur. Le bouton ne fonctionne pas dans Firefox, ni dans Chromium installé en snap (« Failed to initialize »), ni sur le téléphone. Autre solution qui marche : esptool.py --no-stub write_flash -fm dio -fs 4MB 0x0 wifi-radar-esp32.bin

  1. 1. Sur l’ordinateur Ubuntu

    Ouvrez cette page dans Google Chrome (ou Microsoft Edge).

  2. 2. Droits série (une seule fois)

    Dans un terminal :

    sudo usermod -a -G dialout $USER

    Fermez la session puis reconnectez-vous (ou redémarrez) pour que le groupe s’applique.

    Si le port n’apparaît pas et que vous avez le paquet brltty, il peut gêner le port série. Retirez-le seulement si vous n’utilisez pas de plage braille : 

    sudo apt remove brltty

  3. 3. Brancher la carte

    Branchez l’ESP32 au PC avec le câble USB-C. Dans la liste des ports, choisissez celui qui ressemble à ttyUSB0 ou mentionne CP2102 (Silicon Labs).

  4. 4. Lancer l’installation

    Cliquez sur Installer le microprogramme, choisissez le port, puis confirmez. Si la connexion échoue, maintenez le bouton BOOT enfoncé et réessayez.

  5. 5. Configurer le Wi-Fi du salon

    Avec le téléphone, rejoignez le réseau WiFi-Radar-Setup. Une page de configuration devrait s’ouvrir ; sinon allez à http://192.168.4.1/setup. Entrez le nom et le mot de passe de votre Wi-Fi. Ils restent dans la carte, ils ne sont pas envoyés ici.

  6. 6. Ouvrir le radar

    Revenez sur votre Wi-Fi habituel, puis ouvrez http://wifi-radar.local ou l’adresse IP indiquée dans le moniteur série (115200 bauds). L’app se connecte alors toute seule au capteur.
